# Zero Sushi — сайт и админка

Доставка суши, пиццы и чикена, Петропавловск · Instagram @zerosushi.petro · WhatsApp +7 747 254 26 77

```
index.html      витрина: сеты, роллы, пиццы, чикен и комбо, соусы и напитки, корзина, заказ в WhatsApp
admin.html      админка: заказы, меню, акции, «О нас», настройки
js/store.js     данные: сервер sites-api (сайт «zerosushi»), запасной вариант — data/menu.json
data/menu.json  меню по умолчанию
img/            фото сетов и блюд из Instagram
```

Админка: тот же адрес + `/admin.html`. Первый вход — экран «Подключение сайта»:
ключ разработчика + пароль для владельца (делается один раз).

Меню взято из Instagram: сеты — из постов 2026 года; роллы, пиццы, закуски и напитки —
из актуальной истории «Меню» (цены 2025 года, проверить у владельца).
